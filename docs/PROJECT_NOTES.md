# Project Notes

## Major-project positioning

Veda Nexus is designed as an internal operations workspace rather than a simple CRUD demo. The dashboard gives a management view while individual modules support day-to-day operations.

## Suggested demonstration flow

1. Start on Dashboard and explain the KPI cards.
2. Open Services and add a new technology service.
3. Use search to locate a service by owner/category.
4. Open Programs and demonstrate training/internship tracking.
5. Open Customers and register a synthetic customer.
6. Open Inquiries and create a service request.
7. Change an inquiry from Open to In Progress or Resolved.
8. Open Reports and explain the operational breakdowns.
9. Export a dataset to CSV.
10. Show the GitHub repository and README.
